Roland 的新玩具: 吉他合成器 VG-99

Roland VG-99 Guitar System

VG-99 是樂器大廠 Roland 最近研發的新產品. 外觀上跟上一代的 VG-88 有很大的差異.

Roland VG-88 Guitar System

VG-88 就外觀上看起來很直覺的就是適合現場表演的吉他手使用. 功能導向也比較像是一般的綜合效果器那樣, 但是其原理又跟綜合效果器有所差異. 所以一般會叫他是吉他專用的模擬合成器.

VG-99 除了有 VG-88 的功能之外, 另外也有 GR-33 的功能. 也就是說, 他可以送出 MIDI Message.

VG-99 的聲音引擎還有包含經典的 GR-300 類比合成器核心. GR300 是著名的吉他手 Pat Metheny 喜歡使用的設備之一. 其他的部分就是模擬各種木吉他, 古典吉他, 經典效果 ... 等等.

另外 VG-99 也把一般 Roland 合成器上才有的 D-beam 控制器作進去. D-beam 是一個光感應器, 樂手可以透過手指在空中移動, 控制聲音或者送出指定的控制訊號, 讓聲音作出適度的變化, 功能上有點類似吉他的踏板, 或者是鍵盤的推桿. 但是因為是用光感應控制, 所以表演時, 讓樂手可以有一些舞台肢體動作. VG-99 加入這樣的新功能表示著, 本來在舞台上就蹦蹦跳跳的吉他手, 又多了一個耍寶的方式~~

當然有得有失, 那麼多很棒的功能, 相對的就少了一些東西, 如照片看來就知道, VG99 現場表演大概就不是很方便, 所以要外接一些踏板控制器之類的.

相關產品:

  1. Roland VG-8: 第一代吉他模擬系統, 95' 年的劃時代產品, 已退出市場多年.
  2. Roland VG-88 2.0: 廣受好評的產品! 但是在台灣玩的人不多. 國外很流行. 我一直很想敗來玩 ....
  3. Roland VG-99: 這篇文章的主角!
  4. Roland GR-300: 第一代類比吉他合成器, 著名吉他手 Pat Metheny 是愛用者. 他的專輯裡有很多像小喇叭的聲音是用吉他 '吹' 的!~~
  5. Roland GR-33, GR-20: Gutar Synth (吉他合成器), 可以把吉他當成輸入工具. 之後的玩法就跟一般的合成鍵盤一樣.
  6. Yamaha G50 + G1D
