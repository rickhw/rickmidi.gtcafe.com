轉調曲例

August 2, 2008 · 5 min read

轉調簡單的概念就是指曲子進行中調性改變，當我們說 "一首歌是 C 大調" 時, 這句話包含一些很重要的訊息:

  1. 根音 (Root, 主音, 最重要的音) 是 C
  2. 音階的音程關係是: 大調關係 (全全半全全全半)
  3. 存在著一組大調順階和弦

詳細關於 "調" 的概念，請見小弟的 調、調式及轉調 一文的介紹.

所以我們說轉調, 指的就是改變調的根音、或者調的音程關係。

  • 根音改變像是 C 大調轉 A 大調, 音程關係依舊是大調關係
  • 音程關係改變像是 C 大調轉 C 小調, 根音依舊是 C (平行調)

因為這樣的改變, 造成在聽覺上呈現的感覺改變, 這些感覺使用的時機大概有以下:

  1. 加強情緒、主題重現 (升半音, 或全音)
  2. 戲劇性 (直接轉調，配樂)
  3. 男女對唱 (根據男女音域來設計調性)
  4. 主曲、副歌、間奏、前尾奏、橋段等段落的轉折
  5. 根據樂器特性安排轉調 (口琴、Saxophone … 等固定調樂器)

樂理上常見的轉調關係，通常利用終止式作轉接。只要找到目標調性的終止與原調性可以銜接，大概都是 ok 的。
樂理上常見的轉調技巧有下面幾種：

  1. 平行調：主音相同的大小調, Ex: C major <--> C minor.
  2. 關係調：組成音一樣的大小調: Ex: C major <--> A minor, 調式音階也是關係調. D Dorian <--> F Lydian 組成音都是一樣的.
  3. 屬調：以原調屬音 V 作為主音的調, Ex: C major --> G major.
  4. 下屬調：以原調下屬音 IV 作為主音的調, Ex: C major --> F major, C minor -> F minor

其他常用的轉調：

  1. 升一個半音或者一個全音, 用目標調的 V 級和弦作轉接點. Ex: C 轉 C# 可以在轉折的地方放入 G# 和弦作轉接.
  2. 直接轉調: 跟樂理沒啥關係, 轉調方式完全是天外飛來一筆. 聽覺上充滿戲劇性.

很多歌曲都喜歡用平行調設計, 例如 A -> C -> Eb, 這是個很常見的例子.

  • A -> C 可以想像成 A -> Am (平行調)
  • C -> Eb 可以想像成 C -> Cm (平行調)

這種曲子的設計, 通常在間奏, 或者主歌, 副歌之間做轉調, 很容易把情緒的張力拉開. 尤其是男女對唱的曲子更是適合這樣的設計. 更詳細介紹請看 "小調音階 (Minor Scale)".

另外這種平行調常用的地方就是藍調, 例如上面的 A <--> Am, 以一首 A Blues 來說, 不管是 A Major 還是 A Minor, 常常會交互使用, A Major Scale 就會跟 A Mixolydian 混著用, A Minor 就直接換成 A Blues Scale, 或 A Dorian Scale 帶入, 所以一首 A Blues 來說, 最常使用的音階大概就是 A Mixolydian + A Blues Scale + A Dorian Scale. 這是最常見的音階素材了. 其中有人把 Mixolydian + Blues Scale 稱為 Hip Scale.

扯遠了, 類似的例子非常多, 以上只是舉一些例子來驗證而已.
