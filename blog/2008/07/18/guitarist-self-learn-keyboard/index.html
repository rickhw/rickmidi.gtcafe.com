吉他手如何自學鍵盤?

July 18, 2008 · 5 min read

也是一篇我在鄉民站 Keyboard 版 po 過的文字, 主要是討論吉他手如何自學鍵盤. 這邊說的 "學鍵盤" 指的是基本的鋼琴演奏技巧, 不包含合成器, MIDI 編曲等概念.

當然初學者最好還是要有人帶. 我是已經積非成是, 積沙成塔, 無藥可救很多年了, 所以才有以下的歸納學習法則. 這些東西是我自己很多年的經驗累積起來的, 不是很正規的. 根專業的比起來是不值一提, 所以各位前輩看到笑笑就好, 不要太介意裡面的練習方法 :D

文中提到的練習方法分成音階, 和弦, 琶音, 獨奏 ... 等部份. 概念上就是把吉他的學習概念搬到鍵盤這樣而已.

鍵盤我都是自己學的. 我剛開始學鍵盤的方法就是, 吉他上怎麼彈,
全部搬到鍵盤上 ... 例如左手和弦 + T1 21 31 21, T12 321, 左手練累了, 換右手, 彈旋律, 音階.
當然你要先知道吉他彈出來的 T1213121 實際談的是哪一些音,
以 C 和弦來說就是 C G C G E G C G ... 等, 其他類推.

基本上剛開始學習在鍵盤上彈旋律, 音階 (只用白鍵), 比吉他簡單很多.
但是彈和弦卻比吉他難很多.
上述的東西練起來後, 可以找理查的歌來鍊, 練個左手十度音.
想強化一下手指頭就去鍊哈農吧 ...(我知道有人不推薦這個..)

如同一些版友的描述, 當學到轉調時, 吉他明顯比鍵盤簡單很多.
只要熟練五個基本的 Pattern, 三種三連音 Pattern ... 大部分的調都不難彈.

鍵盤轉調不一樣, 沒啥好說的, 練吧!
可以的話, 五度圈兩邊各延伸四個調 (Ab Eb Bb F C G D A E) 都練一下.
不要太依賴鍵盤的 transport ... 除非老是遇到 Db, Gb (F#), B 那種吹鬍子瞪眼睛的 ...

和弦的話, 三和弦兩者我覺得都不難.
吉他把封閉練好, 五個基本形狀 (C G D A E, 剛好是五度圈) 練好,
會推算全音半音, 會簡化的按法, 這樣大概就差不多了.
鍵盤的話, 三和弦三種轉位, 左右手都要鍊.
各調的和弦轉位也是一樣要練 ...

七和弦, 吉他也算簡單, 鍵盤我覺得比吉他難很多.
吉他只要會三和弦, 七和弦大概就會按了, 而且通常不會太難聽.
鍵盤的七和弦推算也不難, 四個基本轉位也不難推算.
但是, 要按出好聽的七和弦聲響卻要思考一下 Voicing 的問題 ...

不過吉他跟鍵盤七和弦琶音都不容易. 要花心思鍊.

七和弦以上的東西, 平心而論, 兩者都不容易.
但是要按出好聽的, 我覺得鍵盤比較容易. 只
要你懂得如何在鍵盤上安排出好聽的七和弦聲響,
基本上大概就會安排其他的 extended chord 了.

反而是吉他, 超過七和弦的延伸和弦 ..
按其實不難, 按出好聽的不容易, 因為就只有那六根弦@@....
有時候不夠用, 勉強把想強調的 tension 放在聽起來不明顯的地方,
雖然按對了, 但是沒味道 ...

另外技巧方面的就是琶音.
我到覺得吉他的 arpeggios 比較難一些, 不管是單純琶音, 還是金屬愛玩的掃弦 ...
尤其是一些比較特別掃弦技巧, 同時要跨弦, 手指又要張很開, 又要把悶音做好.
有時候眼睛脫窗, 看錯格就變成很爵士的 metal, 或者很前衛的爵士 (就是四不像@@) ...

不過鍵盤應該也有類似難度的技巧吧 ~
例如大範圍的移動之類的 .... (這邊需要專業的來補充XD)

還有就是獨奏, 我個人覺得, 初學時鍵盤比吉他容易很多.
當然兩者都必須已經瞭解基本的和弦和音階概念.

很多初學音樂都會學小星星.
鍵盤可能左手 Do So Mi So, 右手 So Mi Mi, Fa Re Re ...
我相信沒有基礎的初學者也可以很快彈出來.

但是同樣的東西搬到吉他上, 一把要彈出來,
沒有相當的基礎訓練, 可能連前面四小節都很難彈好.

至於電吉他的效果器跟鍵盤的合成原理方面.
兩者我覺得都一樣 .... 很複雜... 都是無底洞 ...
就像學古典吉他跑去彈電吉他, 我只能說他在電吉他方面, 大概只懂一半.
同樣的, 學鋼琴的跑去玩鍵盤, 我也只能說鍵盤他只會一半.

不過扯這麼多, 我覺得最難的還是用鍵盤來彈吉他的東西最難, 或者用吉他來彈鍵盤的東西 ...

結論：

很多吉他手都有在玩錄音, 編曲, 音樂製作有的沒的 ... 可是剛開始可能最痛苦的, 覺得最難搞的, 除了一堆的 MIDI 概念, 音源, 接下來就是會遇到如何把音符放到編曲環境了. 很多人會想找 MIDI Guitar, 但是通常效果都差強人意, 或者成本太高, 最後來是回到鍵盤上.

如果有學過鋼琴那就一切 ok, 如果沒學過, 那真的是玩起來很辛苦. 然後一些吉他手就會開始想學鍵盤 (簡單的鋼琴演奏技巧) .... 這樣的朋友, 也許試著學一些鍵盤, 對於音樂製作 / 編曲 / 練團 / 音樂的概念都會所幫助的!
