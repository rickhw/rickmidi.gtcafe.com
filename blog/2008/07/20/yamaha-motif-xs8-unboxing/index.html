Yamaha Motif XS8 開箱文

July 20, 2008 · 5 min read

第一次寫開箱文, 沒想到是寫新的小老婆 Yamaha Motif XS8. 先看圖吧!

全新剛到貨, Made in Japan

箱子正面, 比 Fantom X8 小一點, 輕一點, But ...出現了!! 六塊寶利龍, 上下把琴固定住. 感覺比 X8 的兩塊用馬糞紙做的固定座好.還沒離開紙箱的 Yamaha Motif XS8 主機,
其中還包含說明書, Cubase AI4 光碟, 電源線 ... 沒有 USB 線@@..
箱子雖然比較小一點, 但是, 實際的機身長比 X8 長約五 ~ 八公分開機了!!

Welcome to Yamaha Motif XS!

拍一張跟 X8 一樣的角度, 嗯, 還是 X8 比較漂亮XD

更新 OS, Linux Base 的 OS

看完照片開始寫心得. 玩了一個晚上, 把主要的功能都玩過一次, 同時也跟之前的琴 Fantom X8 做一下比較. 當然一開始還是要說一下主要想換琴的動機.

Motif XS 最吸引我的當然不會是他的外觀, 主要是因為他有高達 6000 多組的 arpeggios (琶音) 可以讓使用者直接使用, 而且這些 arpeggios 是針對不同樂器/曲風設計過的, 例如有吉他的 Riff, 鋼琴的伴奏, 舞曲用的 loop, walking bass, blues riff .... etc. 這意味著, 我們可以從這些現成的素材中找靈感, 直接套用在歌曲上, 或者改編. 對於創作者來說, 這是一個很不錯的素材資料庫. 另外 Motif XS 提供四組 arpeggios 同時運作, 所以他幾乎可以說是一台伴奏琴.

另外還有一個原因就是跟電腦的整合. Motif XS 可以與 Cubase AI 完美整合. 當然這是因為 Steinberg 被 Yamaha 併購了, 所以完美整合其實是理所當然的. 當然另外一家大廠 Roland 也把 Cakewalk 併購了, Fantom G 系列也許會跟 Sonar 整合吧!

最後的原因就是琴的機動性. Fantom 系列是用轉盤選 Group, Bank. 而 Motif XS 的音色選擇, 大致上比較正規, 就是固定按三個鍵就可以找到想要的音色. 但就因為這樣, 反而有更高的機動性.

接下來聊聊音色, Motif XS 的波形容量是 355 M, 應該是目前合成器之冠吧?! 當然這邊不跟軟體比. 先做一下我最在意的比較 - 鋼琴. 這邊我個人覺得, Roland Fantom X 對於 "Grand Piano" 這個樂器, 提供的選擇比較多貼心的選擇. Yamaha 雖然自己有做鋼琴, 但是在 Motif XS 上似乎沒有那麼多可以選. 不過好在, Motif XS 的鋼琴取樣做的還不錯~ 沒有讓我失望.

拿一段以前即興 midi 重新過帶, 這段即興段落是去年差不多這個時間錄的, 為了保留當時即興+亂彈的感覺, 所以原 midi 沒有經過任何修改或 quantize. 可惜的是當時忘了先用 X8 過帶, 所以就與著名的鋼琴軟體音源 Ivory 比較吧:

  • Memory Keeper by Ivory - Bosendorfer 290
  • Memory Keeper by Motif XS - Full Concert Grand Piano

嗯嗯, 可能是我的錄音介面不好, 所以感覺兩者有一點落差 ... 大家聽聽就好.

開箱文, 不要寫太多字, 先到這邊! 有空再來針對細部功能寫更詳細的使用心得吧!

PS: 有朋友問我, 為什麼不買 Korg M3. 其實 Korg 的琴我也很想玩玩看, 不過小弟我天生有一個致命傷就是 ... 手汗 ... 所以對於 Touch Pad 的控制器, 基本上暫時不列入考慮 ... 當然 Fantom G 就不要再問啦, 我家不是開銀行的 XDDDD~~~
