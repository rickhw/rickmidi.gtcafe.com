歌曲分析: FF10-2 - Memories of Lightwaves

June 4, 2010 · 9 min read

著名電玩 Final Fantasy X-2 的主題配樂之一. Final Fantasy (以下簡稱 FF, 就是台灣早期雜誌翻譯成 "太空戰士") 雖然是一款 RPG 遊戲, 但是除了遊戲本身的劇情故事, 人物, 場景, 遊戲方式的創意, 最令玩家津津樂道之一的就是他的遊戲配樂, 由日本著名的配樂大師植松伸夫 (Nobuo Uematsu) 譜曲. FF 音樂相關的資訊我就不多說了, Google 可以找到很多相關資訊.

FF 整個系列的音樂一直以來都是我最喜歡的音樂之一, 植松伸夫為 FF 打造的配樂, 不管是什麼樣的場景, 情結, 情緒, 氣氛, 民俗風情, 詭譎, 神秘, 搞笑, 緊張, 奮怒, 悲傷, 歡喜 .... 等等, 各式各樣類似電影的情緒音樂, 他都能夠在遊戲裡, 用音符清楚的刻畫出來. 所以 FF 的音樂系列, 不管是鋼琴演奏系列 (Piano Collection), OST 系列 (原聲帶), Concert 系列 (巡迴交響音樂會), The Black Mages 系列 (黑摩導士, 搖滾 FF), Vocal 系列 (聲樂版)  .... 等, 都是我個人最愛的收藏品. 當然也包涵要分析的這首鋼琴曲.

不過這首鋼琴演奏曲是一個例外, 因為不是植松伸夫譜曲的, 但是依舊掌握了故事情節的張力, 還有主題, 風格也很符合 FF 一向的感覺. 先聽聽看吧, 鋼琴演奏專輯的原曲, 這是較長的版本 (包含變奏約六分半鐘, 另有約兩分鐘長度的版本):

接下來是我個人在練這首曲子時, 所做的前置作業 - 分析歌曲結構, 和弦進行 (左手, 右手我通常都憑感覺彈 XD) ... 等. 整個分析的程序大概如 "如何練一首歌" 的描述. 因為自己只是單純喜歡鋼琴, 所以以下的分析整理, 方式是以流行音樂得和弦基礎為參考基礎. 所以有些分析角度可能會傳統古典理論不太一樣, 但是大部分都是有參考依據的, 歡迎前輩/同好給予指導, 討論. 技巧方面, Youtube 也有很多類似的教學和示範, 我就不在這邊班門弄斧了.

吉他手 (像我一樣) 如果想自學鍵盤演奏技巧, 可以參考我的心得分享: "吉他手如何自學鍵盤" 的介紹, 有我個人多年來自學的心得分享.

完整的五線譜 Google 用 Keyword 應該不難找到, 不過要找的是包含變奏的版本 (8頁). 找不到可以私下 Mail 給我.

接下來就直接開始歌曲和弦的分析.

調號: Bb/Gm

Intro (6/8): Free Tempo
|| Ebsus2 ‧ Dsus2 ‧ | Bbsus2 / / | / / / |
| Dbsus2 ‧ Csus2 ‧ | Absus2 / / | C4/Ab5 / / | / / / ||

|| Bsus2 ‧ Bbsus2 ‧ | Gbsus2 ‧ Absus2 ‧ | Ebsus / / |
| Ebsus2/Db5 / / | Ebsus2/Cb5 / /  | Ebsus2/Ab5 / / |
| Ebsus2/Gb5 / / | Ebsus2/Eb5 / / | C4/Eb5 / / / ||

前奏以 Xsus2 為主要和弦, 因為大二度的聲響聽起來很有 New Age 的感覺, 同時很多時候也會把大二度往上延伸成大九度行成附加九和弦 (Xadd9), 另外 Xsus4, Xmaj7 也是 New Age 很常應用的和弦. 這首歌曲後面很多地方 Xsus2 和 Xadd9 會交互 or 混合使用.

前奏作曲者用 Xsus2 以及半音程堆疊變化帶出主題, 營造出 Lightwave 的感覺. 彷彿在無意間, 翻到十年前的記憶的, 那種一道光閃過的感覺. (請發揮想像力 XDD)

其實像 Xsus2, Xsus4, Xadd9, Xmaj7 這四種和弦, 在鍵盤上隨意彈, 都會很有 New Age 的感覺, 喜歡風潮唱片 / New Age 的朋友, 對於這個聲響應該不會陌生.

另外鍵盤在編這樣的演奏曲時, 通常會把大二度, 完全四度, 大七度, 大九度 .. 等音放在右手, 也就是寫在 Melody 裡. 而左手則負責根音和五度音, 如此可以讓和弦達到很寬廣的遠距聲位 Open Voicing. 類似的想法可以參考 "再談 Guide Tone" 的整理.

這邊的 C4 表示只彈 C 和其四度音. 不寫成 Csus4 是因為 Csus4 包含五度音. 最後五個小節右手固定 Ebsus2, 左手則彈奏遞減的五和弦, 最後以 C4/Eb5 上行琶音做段落結尾.

C4/Ab5 是複合和弦的表示方式, 分別表示兩個和弦, 左手彈 Ab5, 右手則彈 C, F 這兩個音. 如果要把 C4/Ab5 這個和弦用正規的表示方式可以寫成: Absus2 (add6) => Eb F Bb C (1, 2, 5, 6).  其他  Ebsus2/Db5, C4/Eb5 ... etc 也是一樣的表示方式.

不過硬是把這些音全部混合在一起分析, 實在沒啥意義, 因為有時候這樣的獨奏曲, 左右手是互相呼應, 但是卻是獨立的聲部. 這種手法在流行歌曲裡也很常見, 通常就是吉它和 Bass 各自是獨立的聲部, 但是卻是互相呼應的.

Theme 1 (6/8), tempo=66, main motif (主題)
||: Ebadd9 / / | Fadd9 / / / | Gmadd9 / / | Dmadd9 / / |
| Ebadd9 / / | Fadd9 / / / | Gmadd9 / / | / / / :|| x3

Theme 2 (6/8) - tempo=piu mosso (稍微快)
||: Ebadd9 / / | Fadd9 / / / | Gmadd9 / / | Dmadd9 / / :|| x4
|| Cmadd9 / / | Dm / / | Ebadd9 / / | F9sus4 / / ||

這兩段的和弦進行與旋律都是歌曲的主題所在. 編曲的方式就是循序漸進的堆疊, 小範圍主題, 然後重複主題, 把音程範圍擴大, 左手低八度, 右手高八度 or 加入和聲 (八度音, 六度音 ... etc), 把情緒加強. 很常見的編曲方式.

另外, 先嘗試以五線譜的調號: Bb 大調來看這段的級數:

||: 4add9 / / / | 5add9 / / / | 6madd9 / / / | 3madd9 / / / :||
|| 2madd9 / / / | 3m / / / | 4add9 / / / | 59sus4 / / / ||

一段升冪的進行, 往六級靠近, 在三級作迴轉. 以大調角度看到六三這樣的, 實際上就要想到其實是在往小調趨近, 所以聽覺上可以往小調考慮. 最後準備往 Theme 3 時, 又趨向大調, 因為終止在 Bb 大調的五級.

接下來的幾段變奏, 結構比較複雜, 所以我把歌曲的時間也標上, 方便配合歌曲練習.

Theme 3 (6/8): Free Tempo
|| Cm7 / / | / / / | Dm / / | / / / | G5 / / | / / / |
| Bb/onF / / | / / / | C / / | / / / | Dadd9 / / | / / / |
| Ebadd9 / / | / / / | F / / | / / / ||

Bb/onF 這是指 Slash Chord, 改變低音為 F.

Theme 4: Tempo=138, [02:31]
|6/8 Cm9 / / | Am7 ‧ Bbsus2/onF# ‧ | Gmadd9 / / | Em / / |
[02:39]
|4/4 Ebadd9 / / / | Dmbadd9 / / / | Cbadd9 / / / | Fbsus2 (add #11, 13) / / / |
| Bbsus2 / / / | 5/4 / / / / / ||

這段複雜了點, 除了速度, 調號, 拍號也都有變化. 和弦出現 Cbadd9, 不是寫錯了, 而是歌曲調號是 Bb 大調, 原本 E, B 的位置分別表示 Eb, Bb, 所以當要表示 B 的時候, 就必須使用本位記號 or Cb 這樣的方式. 另外 Fbsus2 和弦也是同樣意思.

這邊的 Fbsus2 (add #11, 13) => (Fb Gb Cb + Bb Db). 用到了這些音, 我先暫時這樣分析. 不過應該有其他的名稱. XXX 六和弦 (拿玻里? 我只想到披薩 XDD) 之類的 ..... 待研究 @@....

Theme 5: Tempo=98 [03:03] (沒有三度音)
| 4/4 Eb5 (add6) / / / | Eb5 (add6) / / / |
| Eb5 (add6) / / / | Eb5 (add6) / / / |
| Gb5 (add6) / / / | Gb5 (add6) / / / |
| Gb5 (add6) / / / | Gb5 (add6) / / / |
| A&b7 / / / |

[03:24] 8va
| A&b7 / / / | C7 / / / | C7 / / / | C7 / / / | 0 0 0 0 |

這段的梗就是, 左手和弦大部分都不彈三度音, 改彈六度音 or 七度音. 另外 A&b7 表示只彈 A + G 這個音.

Theme 6: t=108  [03:42] (mp)
|| Eb5 / / / | F5 / / / | G5 / / / | D5 / / / |
| Eb5 / / / | F5 / / / | G5 / / / | / / / / |

| Eb5 / / / | F5 / / / | G5 / / / | D5 / / / |

[04:36]
| Ebmaj9 / / / | Fmaj9 / / / | Gm69 / / / | Dm11 / / / |
| Ebadd9 / / / | Fadd9 / / / | Gmadd9 / / / | / / / / |

Theme6 這段是我個人最喜歡的一段變奏. Melody 的點由舒緩的八分音符, 越來越密集, 節奏越來越強, 情緒往上提升. 最後右手 Melody 變的很密集的 16beat, 左手指剩下全音符; 到 04:36 開始, 左右互換, 左手密集, 右手 Melody 減緩, 然後遞增往主題靠近 ( mf ->f ) . 是非常精采的一段變奏.

和弦的表示: Dm11 表示: Dm7 + 4th, 實際上主要是表示有經過四度音.

Theme7: 4/4, main motif, [04:54]
(f)
|| Ebadd9 / / | F9 / / / | Gm9 / / | Dm11 / / |
| Ebadd9 / / | F9 / / / | Gmadd9 / / | Dm11 / / |

[05:30] (8va) (mp)

| Ebadd9 / / / | Fadd9 / / / | Gmadd9 / / / | Gmadd9 / / / |

經過前面的變奏之後, 再度把歌曲拉回主題, 呼應開頭, 然後也延續了變奏的情緒. 最後漸漸的又用 Xadd9 呼應前奏的 Xsus2.

簡單的整理了歌曲結構, 和弦進行等用法, 主要目的是幫助我個人練習時能夠快速掌握重點.  主要得練習分析想法在 "如何練一首歌" 已經有初略的整理.

去年 Final Fantasy Concert 首次來台灣巡迴, 在國父紀念館, 植松伸夫 本人也有來, 我也有去.  超級感動的. 雖然 TSO (台北市立交響樂團) 的演奏 + 國父紀念館場地實在都不怎樣 (其實很失望 orz), 不過看到植松老大本人穿著日本傳統服飾 (他的 Concert 好像一直都是以日本傳統服飾) 到現場, 就像小朋友看到偶像那種感動一樣 ~~

期望有機會聽到 The Black Mages 來台灣 ~~~
