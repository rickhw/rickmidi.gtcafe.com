Graph Tech - Ghost Pickup System (吉他模擬系統)

August 13, 2010 · 3 min read

這是由 Graph Tech 所研發的一套類似 VG99 的吉他模擬系統, 主要就是讓電吉他有比較 "擬真" 的木吉他的音色, 另外就是讓電吉他也能夠擁有輸出 MIDI 訊號的功能. 但是強調輸出 MIDI 訊號的 Latency (延遲) 更短, 更精確. 是除了 VG99 以外, 另一個讓電吉他有 Acoustic Guitar 和 MIDI 不錯的選擇.

先看看吉他手 Jack Thammarat 的介紹和示範 (第一段和最後一段超像 T-Sqaure 的感覺, 有 EWI 的感覺!!!)

這套產品, 有兩個部分, 主要的是 Saddle Pickups, 有點類似 Roland 的 GK3. 但是他長的不是像一般的吉他的 Pickup 那樣, 而是直接取代原本搖座上的弦枕, 當然這要自己組裝. 組裝很麻煩, 當然他也有提供整組搖座. 如下圖 (摘自 Graph Tech 官方網站):

Saddle Pickup:LB63 Bridge:

Saddle Pickup 是必要的, 安裝了他之後, 需要再選擇提供木吉他音色的模組, 還是 MIDI 模組, 當然也可以都安裝. 這兩個模組分別是 (摘自 Graph Tech 官方網站):

Acouti-PhonicHexpander
木吉他音色的模擬提供 MIDI 訊號的輸出

跟 VG99 一樣, 他可以提供分別提供 MIDI 訊號, 木吉他, 和原始電吉他訊號輸出; 當然也可以把這三個同時混合輸出.

整套 Ghost Pickup System 的安裝比較麻煩, 要對原本的琴很多的手腳, 包含原始的搖座, 配線, 可能也需要鑽洞安裝一些開關, 挖洞提供模組電路板的安裝. 詳細安裝 (官方提供)

不過他的優點就是, 木吉他效果不錯, MIDI Latency 比較小, 反應快. 同類型的像 Roland GK3, 我實際測試過, 彈太快會 Miss 一些 Notes, 而且只要稍微按的不好, 或者按弦太用力, 就會一些 Unwant Notes. 這點是一個很大的優勢.

實際上類似的產品, 除了開頭提到的 Roland VG99, GR-20, Fender VG Strato, 另外 Line6 的 Variax 700 也是類似的產品. 所以吉他手早就已經可以不只是 "吉他" 手 ~~
