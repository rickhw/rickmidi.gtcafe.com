Fantom X8 使用心得

May 5, 2007 · 8 min read

到今天剛好買了一年, 來聊一下這台琴的使用心得. 分成音色, 使用介面, 功能, 外觀, 擴充 ... 等部份.

首先是音色的部份:

  • Piano / 鋼琴: 鋼琴是我最在意的音色, 基本上這台琴的鋼琴我算是滿意. 取樣的鋼琴音色低音厚實, 中音飽滿, 高頻明亮. 鋼琴演奏模式可以模擬鋼琴共鳴的程度, 也可以模擬平台鋼琴琴蓋開和的程度. 只是沒什麼力度分層/動態, 這是算是這台琴比較讓我失望的地方. 後來我又添購了 SRX-02 Concert Piano 這張卡, 在動態的部份, 有不錯的表現.
  • Organ / 風琴: Organ 部份, 有提供了很多經典的 Organ, 都很實用. 我最喜歡加了一點 Distortion 的 PR-F 057 Purple Organ, 從字面上, 還有實際的音色聽起來, 熟悉搖滾樂的人都不難聯想到 Deep Purple 的 Smoke on the Water 這首經典搖滾!
  • Keyboard / 鍵盤類: 主要是大鍵琴跟古鋼琴兩種的音色. 古鋼琴我沒什麼研究, 大鍵琴我到是蠻喜歡這個音色的. 金屬樂團騰雲的經典歌曲 Black Diamond 一開始就用大鍵琴, 很亮麗的音色. Fantom X 提供的大鍵琴除了音色本身很亮麗之外, 大鍵琴撥弦的聲音也都有做到. 所以當彈奏時, 會很清楚的聽到撥弦的聲音.
  • Acoustic Guitar / 木吉他 / Electric Guitar / 電吉他: 也許是因為我自己是吉他手, 所以對於鍵盤的吉他音色通常都沒有啥太大的期待. 不過 Fantom X 的吉他, 其實仔細去聽, 算是做的不錯了, 很多屬於 "噪音" 的部份都有作進去. 電吉他的部份, 因為 Fantom X 內建經典的電吉他 Amplifier Simulator, 所以我覺得如果會用的話, 應該可以做出很棒的效果. 當然我還沒花時間去研究這部份 ....
  • String / 絃樂: 絃樂我不太懂, 所以不作結論. 不過小提琴取樣的很好. 聽說絃樂是 Roland 的強項?!
  • Rhythm Set / 鼓 / 節奏樂器: Standard Kits 是比較失敗的地方, 聽起來有點呆, 沒啥動態. 不過作流行歌基本上還是很夠. 其他很多鼓用來作電音, RnB, Hit Hop 都很適合. 我比較喜歡用的是 StudioX Kit1 這組. 動態的部份後來我添購 SRX-01 Dymanic DrumKits 來補足.

有一些像是電鋼琴 (EP), 敲擊樂器 (Mallet), Bass, 風管 (Wind), 銅管 (Brass), ... 等, 其實我都不是很熟悉那些聲音的特色, 所以暫時不提. 另外合成音色的部份, 像是 Head Lead / Soft Lead / Bright Pad / Soft Pad ... 等, Fantom X 提供了很多各種類型的, 要作比較有張力, 比較華麗的 Solo, 或者是當 Pad, 都是很不錯的.

接下來是使用介面 (User Interface) 部份:

從現場表演 (Live) 跟工作室 (Studio) 個角度來看 UI. 結論剛好是兩個極端. (當然這只是我個人覺得) 這邊指的現場表演不是那種綵排過的表演場, 而是一般 Pub 點歌的場子.

現場表演這台琴的 UI 設計很失敗. 從最重要, 最需要機動性的選音色這點來看, 我想所有的鍵盤手都會選擇 Motif 或者是 TR ... 沒有人喜歡用轉盤來選音色的. Roland XP 系列會成功不是沒道理的. 到現在 XP-30, 60, 80 都還是很多場子的基本配備, 即使他們已經停產多年了.

選音色的問題, 我想到的辦法就是用 Favorite 這個功能來克服, 把常用的音色都先設定好. 這樣會比較快一點. 不過選 Favorite Group 時還是必須使用轉盤 .... 囧rz ....

接下來是分鍵的設定, 因為要仰賴游標的移動, 所以現場設定可能會太慢. 設定分鍵的 Range (Up/Down) 都要用轉盤指定, 應該直接從鍵盤上指定會比較直覺, 這是 Fantom 一個很大的敗筆.

螢幕上得功能大部分都要仰賴游標鍵 (上下左右) 和 Function Keys 配合作操作, 所以要指定好一個功能要按很多下, 才會到想要的地方. 直覺上, 應該多設計一些 Function Keys 在螢幕週邊, 然後直接按就比較快.

這些缺點在現場表演幾乎都是致命傷, 只要鍵盤手對這台琴的操作不夠熟練 (閉著眼睛也要能操作叫做熟練), 現場大概會死得很慘!

當然, 當這台琴放在 Studio 的時候, 以上說得缺失, 都不是缺失. 因為 Studio 並不是需要高度機動的地方. 而 Fantom 這些功能在 Studio 反而都是很實用的.

編曲機 Sequencer 和 Expension Audio Trackers:

功能很強大, 軟體介面很直覺, 基本上會使用 Cakewalk 的人, 不用看手冊也會使用, 配合 Mix, Perference, 還有 Effects 等模式, 基本上是非常方便的! 同時他也提供了很多 Sequencer 基本的功能, 像是 Quantize, Velocity Editor, Move, Insert ... etc.

另外很令人讚賞的就是整合 Audio Trackers ! 提供八軌 Audio Trackers 可以和 Sequencer 同步作業. 然後直接 Mixdown! 這個部分對於創作人真的是很 powerful 的功能!

另外 Fantom X 還有提供 Mastering 功能, 讓作品可以更飽滿. 內定五種預設的 Comp 模式, 很實用且很強大的功能!

Piano Mode (鋼琴演奏模式):

我個人覺得, Roland 對於鋼琴演奏者真的是特別照顧! 把鋼琴演奏當成獨立功能做在面板上, 同時還可以模擬鋼琴琴蓋打開, 共鳴程度, 鍵盤輕重控制. 這一點真的很讚!

同時, 也有針對電鋼琴 E Piano 的操作. 喜歡 Fender Rhodes 的朋友一定會喜歡這個功能!

Arpeggios (琶音), Chord (和弦), Rhythm (節奏):

這個部分不是 Roland 的強項, 或者說 Roland 沒有意願投入在這一塊. 因為競爭對手 Y 牌的琴提供很可觀的功能.... 255 vs 2000 多 ... 嗯嗯 ... 有興趣的朋友可以去看看 Yamaha Motif 的規格.

Multi-Effects (多重效果器):

Fantom 提供了 78 種效果器. 其中讓我留意到的是電吉他的音箱模擬. 包含各式 Amp Simulate, EQ, OD, Dist ... 等. Roland 的想法不難瞭解, 簡單說就是讓吉他手不需要帶效果器, 直接 line-in 到 Fantom 一樣可以做音樂! 我個人也試過, 要調到能夠趁趁趁, 應該是沒問題. 不過我沒有花時間研究裡面的 Dist 怎麼調, 官方有 Demo, 基本上幹 Metal 是沒問題的, 只要會調 ...

其他功能:

其他功能比較少用到的如下,:

  • Sample / 取樣: 取樣編輯功能, 在製作音樂上來看, 是很實用的功能. 不過缺點就是處理速度跟 PC 還是有很大的落差.
  • Patch Editor / 音色編輯: 這是合成器的核心部份, 我只懂基本的原理, 作過簡單的取樣設定而已. Roland 專屬的聲音系統我並沒有花時間研究, 不過大致上, 可以做到很細的設定, 有興趣研究調 tone 的人, 或者念物理的人對這一塊會很有興趣.
  • D-Bean / 光感應控制器: 以前玩 VA7 就有的東西, 不過覺得實用性不是很高
  • Dynamic Touch Pad / 動態打擊板: 可以載入 loop, 現場播放, 不過一次只能放一個 loop ...

外觀:

Fantom 系列的外觀, 說真的, 是同等級的三大廠之中, 最好看的, 花花綠綠 + 五光十色. 看我拍的照片就知道 XD~~

擴充:

這台琴其實本身的功能就已經很強大了, 同時也有很多的擴充功能. 其中大概最被大家所讚場 (同時也是幹譙的) 的就是 SRX 卡的擴充. 讚揚的是 SRX 擴充卡的音色真的很不錯, 幹譙的是好的音色都在 SRX 卡里面, 要另外再買!!!! 而且很貴!!!! 商人咩 ...

另外支援取樣記憶體的擴充, 使用的就是電腦的記憶體 (PC133, 168pin), 最多支援到 512M. 基本上算是很夠用了. 儲存設備是使用 PC Card. 所以只要有提供 Adapter 的 PC Card 都可以使用. 像是 CF + PC Card. 可以支援到 1G. 用來儲存一些設定資料, 也很夠用了.

結論:

很棒的琴, 但是如果是要作場的人, 我個人就不是很推薦了.

玩編曲的, 不用考慮了. 然後另外多準備一點錢, 因為一定會去買 SRX 回來玩 XD~~~~~~~
