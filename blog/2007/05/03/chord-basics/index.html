和弦基礎

May 3, 2007 · 11 min read

我大致上整理一下我自己對和弦理解的整個概念。依據組成音分成四大類：三和弦、七和弦、延伸和弦、其他。和弦的學習和記憶方式可參閱和弦學習地圖，吉他和弦的學習請參閱 "吉他和弦聲位的基本概念"。

三和弦

分成大三、小三、增三、減三等共四種：

和弦名稱組成音慣用表示法例子
大三和弦 (Major Triad)1 3 5XC
小三和弦 (Minor Triad)1 b3 5Xm, Xmi, Xmin, X- (註1)Cm, Dmin, A-
增三和弦 (Augmented Triad)1 3 #5X+, XaugC+
減三和弦 (Diminished Triad)1 b3 b5Xdim, Xm(-5)Cdim

七和弦

記憶上可分為兩大類：

  1. 第一類為基本七和弦，以三和弦為基礎：有大七、小七、屬七、有減七、半減七

    和弦名稱組成音表示法例子
    大七和弦 (Major Seventh)1 3 5 7 (大三 + 大七度)Xmaj7, XM7, X△7 (註2)Cmaj7
    屬七和弦 (Dominant Seventh)1 3 5 b7 (大三 + 小七度)X7C7
    小七和弦 (Minor Seventh)1 b3 5 b7 (小三 + 小七度)Xm7, Xmin7Cm7
    減七和弦 (Diminished Seventh)1 b3 b5 bb7 (減三 + 減七度)Xdim7, XoCdim7
    半減七和弦 (Half-Diminished Seventh)1 b3 b5 b7 (減三 + 小七度)Xm7-5, Xm7(-5), XøCm7-5

    屬七和弦相關的應用請參考：次屬和弦 (Secondary Dominant)、屬七和弦與其延伸和弦的代換、變化引伸音 (Altered Tension Notes) 等介紹。

  2. 第二類為變化七和弦：大七增五、小七增五、小調大七、小調大七減五。

和弦名稱組成音表示法例子
大七增五和弦 (Augmented Major Seventh)1 3 #5 7 (增三 + 大七度)Xmaj7+5, XM7(#5)Cmaj7+5
小七增五和弦 (Augmented Minor Seventh)1 b3 #5 b7 (小三增五 + 小七度)Xm7+5, Xm7+, Xm7(#5)Cm7+5
小調大七和弦 (Minor Major Seventh)1 b3 5 7 (小三 + 大七度)XmM7, Xm#7, Xm(maj7)Cm(maj7)
小調大七減五1 b3 b5 7 (減三 + 大七度)XmM7-5, Xm#7-5, Xmmaj7-5Cm(maj7-5)

延伸 (Extended) 和弦

以七和弦為基礎，增加引申音 (Tension Note)，分成四大類：

一、以屬七 (Dominant Seventh) 為基礎：

和弦名稱組成音表示法例子
九和弦屬七 + 大九度X9C9
十一和弦屬七 + 完全十一度X11C11
十三和弦屬七 + 大十三度X13C13

二、以大七 (Major Seventh) 為基礎：

和弦名稱組成音表示法例子
大九和弦大七 + 大九度Xmaj9Cmaj9
大十一和弦大七 + 完全十一度Xmaj11Cmaj11
大十三和弦大七 + 大十三度Xmaj13Cmaj13

三、以小七 (Minor Seventh) 為基礎：

和弦名稱組成音表示法例子
小九和弦小七 + 大九度Xm9Cm9
小十一和弦小七 + 完全十一度Xm11Cm11
小十三和弦小七 + 大十三度Xm13Cm13

其中，11、13 要不要有九度或十一度音，視狀況而定，可有可無。

四、變化和弦 (Altered Chords)：屬七和弦 + -9, +9, +11 (#4, b5), -13 (#5)。 (註1)

和弦名稱組成音表示法例子
X7 alt屬七 + (-9)X7-9C7-9
X7 alt屬七 + (+9)X7+9C7+9
X7 alt屬七 + (+11)X7+11, X9+11C7+11, C9+11
X7 alt屬七 + (-13)X7-13, X9-13, X11-13C7-13, C9-13, C11-13

Altered 是改變 (Change) 的意思，Altered Chord 是一種以 Shell Chord 為基礎的 Extended Chord，它是一個自由度很高的和弦，所以 lead sheet 上其實未必會寫出完整的 altered notes，有時候只會標記 X7 alt 來表示，樂手可以自由發揮，通常可以彈 Altered Scale。

Altered Chord 最有名的應用就是 E7+9 (或寫成 E7#9)，這個和弦因為傳奇吉他手 Jimi Hendrix 的慣用而得名。因為結合了藍調音而造成非常有有特色的聲響，而且又由 Jimi 所慣用，所以又稱 Jimi Hendrix Chord。相關 Altered Chord 和 Shell Chord 的介紹說明，請參見小弟的文字：變化引伸音 (Altered Tension Notes)、Shell Chord

其他

  • 加 (Added) 和弦 (也有人翻成 增加和弦、附加和弦)：以三和弦為基礎，增加九度以上的音。

  • 加九和弦: 大三和弦 + 九度 => Xadd9

  • 加十一: 大三和弦 + 完全十一度 => Xadd11

  • 掛留和弦 (Suspended Chord)：以三和弦為基礎，改變原本三度音為二度或者四度，形成 Suspended 的聲響特性。

  • 掛留四: 1 4 5 => Xsus4

  • 掛留二: 1 2 5 => Xsus2

  • 掛留七, 九和弦: 改變七或九和弦的三度音, ex: X7sus4, X9sus4

  • 六 (6th) 和弦：以三和弦為基礎，增加六度音。有些時候可以代理 I 級。

  • 大六：大三和弦 + 大六度 => X6

  • 小六：小三和弦 + 大六度 => Xm6

  • 六九和弦：以三和弦為基礎，增加六度音、九度音。注意，不是以七和弦為基礎。

  • 大三和弦 + 大六度 + 大九度 => X69

  • 五和弦：又稱 Power Chord，因為沒有三度音，所以沒有大小之分

  • 強力和弦 (Power Chord)，電吉他慣用和弦 => 1 5 => X5

  • 轉位和弦 (Inversion) : C/E --> Bass 為和弦內音

  • 複合和弦 (Polychord)

  • 分數和弦、分割和弦 (Slash): C/F --> Bass 不是和弦內音

  • 複合和弦: CM7/D --> Cmaj7 + D 和弦的組成, 也就是 C13 (+11)

  • 掛留四和弦: 某一些複合弦因為低音的加入之後造成具備了 sus4 的和弦聲響, 例如:

    |
    | |
    | 和弦名稱 | 組成音 | 對應掛留和弦 | 掛留和弦組成音 |
    | Dm7/G | D F A C / G | G9sus4 | G C D F A |
    | Am7/D | A C E G / D | D9sus4 | D G A C E |
    | Cm7/F | C Eb G Bb / F | F9sus4 | F Bb C Eb G |
    | Bbm7/Eb | Bb Db F Ab / Eb | Eb9sus4 | Eb Ab Bb Db F |

    寫成複合和弦會比寫 sus4 的可讀性高.

註：

  1. 關於加減記號 (+ -) 、升降記號 (# b) 、小和弦 (minor) 在和弦的標示法，國內外各種表示法繁多，包含一些製譜軟體、教材也都有各自的標示法。下述三種常見的表示方式，讀者要能夠自行分辨其中的差異。

    一、『-』表示小和弦：像有些教材、樂譜 (Ex: Berklee 的教材) 小三和弦用 "C-" 表示，小七和弦用 "C-7" 表示。如果要使用這種表示法，那麼建議表示增減音程的時候使用升降音記號 (#、b) 來表示正負符號，例如 A-(7#9) = Am7#9。

    二、『-, +』表示音程變化：如果要使用 + - 符號作音程變化，那麼通常會用來標示五度音、和超過八度以上 (九、十一、十三度音) 的音程。這種用法跟第一種會有衝突，所以建議小和弦用 Xm 表示。

    三、『-, +』單獨使用：而加減記號在單獨使用的時候 (不是用來修飾某個特定音程)，習慣上指的是五度音的變化。寫法是直接接在和弦名稱後面，然後最後再加上修飾的音程。例如 Cm+7 = Cm7+5、Dm-9 = Cm9-5、C+ = Caug、Cm- = Cdim。我也看過一些樂譜把加減標在數字後面的寫法，像是 C7+ = C7+5。這種用法純粹用在修飾五度音變化的和弦是可以的，但不適合用在修飾超過八度音的和弦，像是 C9#11 如要要變化五度音就不適合用使用了，看起來容易混亂。

    如果有五度音和九度音都有變化的時候，那麼建議就全部寫出來，或者使用升降記號，二擇一。例如 C7 (+5-9) = C7 (#5b9)、A7 (-9-13) = A7 (b9b13)。屬於修飾的延伸音 (Tension notes) 習慣上會上標或者用小括弧，這樣 Player 就可以隨機應變 (簡單說，可彈可不彈) 。當然看到這種變化音程的，實際上 realbook 會寫 C7 alt 變化和弦。

    上述兩者兩者 ("減記號表小和弦" 和 "加減記號表升降音") 不要混著用，否則容易跟增和弦 (Augmented) 搞混，原本的 Cm7- 是否就可表示成 C-7- ? 所以在閱讀樂譜、音樂教科書的時候，稍微留意這些小地方就不難看懂作者的用意了。

    和弦表示法 (Chord Expression) 在不同出版社、排版製譜軟體、教學學派、甚至樂器都會有不同的慣用表示法、寫法。

    吉他可能會習慣用 +, - 表示音程，所以吉他的屬七變化和弦 (Altered chord)：如 E7-9 (E G# B D F) 會用 +, - 表示，如下圖一是 jazzguitar 網站上的 Guitar Chord Finder 的表示法；而鍵盤、鋼琴會習慣用 E7b9 表示，圖二是 jazzpiano 的表示法。實際上這兩個表示的是同一個東西，讀者只要能夠瞭解他其實就是屬七加上一個 Tension 就可以了。

  2. 大七和弦 (Major Seventh) 的表示法早期台灣的書習慣都寫 Xmaj7，錄音室習慣用三角形△表示大音程，或者直接表示大七音程。這幾年很多從音樂學院回來的老師們所編寫的書開始用大寫表示大七，例如 MA7 、M7 這樣的記法，或者把這些描述上標於根音、或者用小括號廓住。這些記譜法依個人習慣、使用地方會有一些差異，不過應該不難區分。只要稍微留意即可。
