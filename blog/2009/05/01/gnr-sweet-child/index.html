GNR - Sweet Child O' Mine

May 1, 2009 · 9 min read

槍與玫瑰 (Gun and Rose) 的超級經典 - Sweet Child O' Mine, 俗稱甜小孩, 算是 Guitar Player 的必練國歌了. 歌曲本身很有意思, 主要有 Slash 那令人難忘的吉他前奏, 配上 Gibson 聲音的典型代表, 還有主唱 Axl Rose 那個有點歇斯底里唱腔, 加上最後 Slash 又來一段 Solo, 把歌曲帶到另一個高潮.

接下來我嘗試來分析這首曲子有那些獨特的地方, 除了吉他的技巧之外, 歌曲獨特的和弦進行是值得拿出來討論的.

歌曲分析的內容提供一個對音樂的思考方式, 不見得正確, 或絕對, 僅供參考, 歡迎大家一起討論.

以下是整首歌曲四大段落的和弦進行:

Intro Verse:D / / /Dadd9 / / /
G / / /G / / /
Chorus (Sweet child o' mine):A / / BC / / /
Bridge I (Guitar Solo):Em / / /C / / /
Bridge II (Solo w/wah):Em / / /C / / /
Outro (Where Do We Go):Em / / /G / / /

分析這首曲子, 分成幾個部分來看:

  1. 主要調性
  2. 各段落裡的和弦進行分析

主要調性:

四大段的和弦我寫的不是某個調的和弦數字級數, 而是完整的和弦名稱, 因為這首曲子本身來看, 雖然從和弦的使用來看, 可以大概猜出用的都是 G 大調/E 小調的順階和弦, 但是實際上和弦和旋律裡都藏有一些其他 outside 的音 (標紅色的部分), 但是整體來看我們還是可以判斷他是屬於哪個大調.

判斷歌曲的調性主要的方式還是以終止式來看, 看看各段落的最後一小節, 除了 Chorus 以外, 其他都是 D / Dsus4. 所以從這個來看, 我們會把這些段落都當成是 G / Em 調來看. Bridge I, II, Outro 裡面有 Em - Am, 剛好是 E 小調的 I-V, 所以他也是 G/Em 的成員, 所以整首歌來看, 就當作是 G/Em 來看, 記譜時調號也不會有太多的升降記號.

另外判斷調的方式, 可以從現有譜上的調號來判斷, 大部分這首歌曲的調號都是只有一個升記號, 所以直覺的就是跟 G/Em 有關. 從此切入也是一個方式. 當然有些譜也會寫 D 大調的調號.

Intro/Verse:

|
| |
| ||: | D / / / | | Dadd9 / / / | | C / / / | | Cadd9 / / / | | |
| | | G / / / | | G / / / | | D / / / | | D / / / | :|| |

從 G 大調的角度來看和弦進行級數會是:

|
| |
| ||: | 5 / / / | | 5add9 / / / | | 4 / / / | | 4add9 / / / | | |
| | | 1 / / / | | 1 / / / | | 5 / / / | | 5 / / / | :|| |

看似屬於 G Major 沒問題, 不過實際上和弦進行聽起似乎會趨向其他的東西. 如果團裡只有一把吉他, 我個人喜歡把這裡的Cadd9 改成 Csus4 , Dadd9 改成 Dsus4 來彈 (如果我是彈 Lead Guitar, 就會彈原本的 Xadd9, 為什麼我會這樣彈, 吉他手應該不難了解) 所以常常會有以下的一些想法:

Csus4 用到的音為 C F G, F 為 G 的 b7 級, 造成符合調式 G Mixolydian 的條件:

  1. G Major Base - 具備 G 大調的終止和弦 - D
  2. 包含 G Mixolydian 的特徵音 b7

所以這段我有時候會把這段當成 G Mixolydian 來玩. 不過不盡然完全如此, 因為段落的開頭為五級, 這是比較奇怪的地方, 大部分歌曲會從 T (主要和弦) 開頭, S (下屬和弦) 或 D (屬和弦) 結尾, 即使 Jazz 也是從二級開始. 所以判斷為 G Mixolydian 這的結論要保留, 請繼續看後面的分析.

Chorus (Sweet child o' mine)

|
| |
| ||: | A / / B | | C / / / | | D / / / | | Dsus4 / / / | :|| |

這段跟 Verse 有點不一樣, 從大段落來看, 他或許是像是 G 大調的終止 - 結束是 D, 但是這邊最後出現的是 Dsus4, Suspended 4th 一般會用來修飾一級/五級和弦. 所以這邊以和弦的角度來看可以判斷成 V of G, or I of D, 也就是以下兩種可能角度:

G Major

|
| |
| ||: | 2 / / 3 | | 4 / / / | | 5 / / / | | 5sus4 / / / | :|| |

D Major

|
| |
| ||: | 5 / / 6 | | b7 / / / | | 1 / / / | | 1sus4 / / / | :|| |

G Major 來看, 從段落後面找不到 V - I of G 或者 IV - I of G. 也就是最後聽起來沒有趨向 G 大調的感覺. 只有前面的 | A - B - C | 是升冪進行, 有 G major 的感覺.

從 D Major 來看, 這裡有一個 b7 - 1 (C: C E G - D: D F# A) 的進行, 聽起來會有 Vm7 - I (Am7: A C E G - D) 的感覺, 它聽起來會具備趨向 D 的終止感覺. 或者直接將 b7 級解釋成 Modal Interchange 就比較容易了解. 所以後面的三個小節, 聽起來會趨向 D 這個音, 不管是趨向 D Major or D Minor. 因為這邊實際的和弦是 D, 所以把這段解釋成趨向 D Major.

所以整段以 D Major Base 來看, 這個 b7 進行符合 D Mixolydian 的順階和弦.

級數IIIIIIIVVVIVII
D Major ScaleDEF#GABC#
D Major 順階和弦DEmF#mGABmC#dim
D Mixolydian ScaleDEF#GABC
D Mixolydian 順階和弦DEmF#dimGAmBmC

(更多請參閱 "淺談調式和聲" 的介紹. 搖滾類的曲子, 用順階三和弦就夠了).

而原本以 G Major 來看似不合理的 A 和弦, 以 D Major 為基礎來看待整段, 一切就是那麼的想當然爾. 而會改變的只有調式的特徵音部分, 也就是 C 的部分 (註).

分析到這裡會發現, 第一段 Verse 其實有類似的現象, 所以我們再回到第一段:

|
| |
| ||: | D / / / | | Dadd9 / / / | | C / / / | | Cadd9 / / / | | |
| | | G / / / | | G / / / | | D / / / | | D / / / | :|| |

改成用 D Major 的角度來看:

|
| |
| ||: | 1 / / / | | 1add9 / / / | | b7 / / / | | b7add9 / / / | | |
| | | 4 / / / | | 4 / / / | | 1 / / / | | 1 / / / | :|| |

其中的 G - D 看成 IV - I of D, b7 理由同 Chorus.

所以一直到 Guitar Solo 之前, 整段都可以看成 D Mixolydian, D Mixolydian 音階只有一個 F#, 調號上跟 G 大調是一樣的, 所以很多時候都會用 G 大調來參考對應. 吉他上的 D Mixolydian 跟 G Major 的音階指型長的是一樣的, 只是根音位置不一樣.

這種例子在藍調裡很常見, E Mixolydian 的調號跟 A 大調一樣, 調號只會有三個升記號, 所以有時候會用 A 大調角度在看.

Bridge I (Guitar Solo)

|
| |
| | ||: | Em / / / | | C / / / | | B / / / | | Am / / / | :|| |

Bridge II (Guitar Solo w/wah)

|
| |
| | ||: | Em / / / | | C / / / | | B / / / | | Am / / / | :|| |

Outro (Where Do We Go)

|
| |
| | ||: | Em / / / | | G / / / | | Am / / / | | C / D G | :|| |

接下來這三段, Guitar Solo 從和弦進行和旋律線 (和聲小調) 來看, 用 Em 來解釋就可以.

很粗略的分析了這整首歌, 這些東西只是為瞭解釋一些現象, 把他們合理化, 或者系統化. 另外一個角度就是揣摩作曲者的思路, 他在寫這首歌時腦袋在想啥. 當然這些解釋方式不見得正確, 如果有什麼想法, 歡迎提出來討論.

最後來聽聽看 Slash 本人聊這首曲子 - Guitar Center Sessions: Slash-Sweet Child O' Mine

註：(New: 20100205)

一些細心的朋友看到這段可能會有一些疑惑, 以 D Mixolydian 來看, 他的順階 V 級是 Am7,
而 D Major 順階 V 級是屬七和弦 A7, 如果歌曲用的是 D Mixolydian, 那麼 Chorus 裡第一個的 A 和弦要怎麼解釋?

調式這種東西的應用, 還是以原始自然大/小調為參考指標, 也就是 D Mixolydian 還是以 D Major 為參考調性 (網路上有人會用 "中心調" 來形容 D Major). 意思就是說, 因為 D Major 的 VII 級在歌曲進行中暫時性的改變, 所以只判斷有特徵音的和弦, 這邊就是 D Mixolydian 的特徵和弦 C, 其他的, 依舊是原本的 D Major 的順階和弦, 所以 Am 出現是 ok 的.

換個 Rock 常見例子, Rock 常用自然小調, 也很常用和聲小調,

A 自然小調: A B C D E F G A
A 和聲小調: A B C D E F G# A

A 自然小調 => 五級: Em7    一級: Am7: A C E G
A 和聲小調 => 五級: E7       一級: Am(Maj7): A C E G#

其實 Rock 裡常會看到小調裡出現屬七和弦 (X7), 但是很少會看到小調大七和弦 (XmMaj7).

因為自然小調只是暫時 "借用" 或者 "改變" 原本的七級 G -> G#, 但是, 歌曲大段落來講, 歌曲還是以自然小調為主; 以應用層次性來講, 除了自然小調, 裡面可能還包含了和聲小調, 搞不好還有旋律小調, Dorian, ... etc.

調式應用亦是如此, 通常只會強調特徵音的相關和弦 (特徵和弦), 剩下的還是原本的自然大小調為主. 如果硬要把整個調式和聲套上去, 那很容易造成調性不明, 終止不清楚的問題, 到最後亂成一團 (非常的前衛?).

因為我們人的聽覺 (或者說西洋音樂理論), 還是以自然大小調做基本參考的.

相關和聲小調的基本概念請參閱 "小調音階 (Minor Scale)" 的說明。
