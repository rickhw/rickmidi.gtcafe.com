吉他需要練各個調嗎？

December 4, 2009 · 5 min read

吉他學一陣子之後，開始就會學習封閉和弦、各調音階的推算，之後漸漸的就會遇到 "調性" 的觀念。 C 大調、D 小調、Eb 大調、Bb 小調，不大不小的 A 中調 ~!@#$%^&*().............

然後問題就來了，那麼多個調，每個調都有順階和弦，每個調都有音階，那要每個都要各自練嗎？還是只要把常用的 Pattern 把位練熟再推算就好？

對於比較屬於休閒性質的學習者，一般來說 C 與 G 調的音階和順階和弦兩個練熟，加上基本的演奏技巧和基本的節奏訓練，基本上已經可彈很多歌曲了。

但是面對如果是比較認真，想要演奏難度高一點的曲子，甚至是想成為專業音樂人的學習者，答案將會是很直接、且很肯定的：要！而且要能夠 (手上不可以有任何樂器) 說出某個調的級數和弦名稱，對應的關係調、平行調級數。

吉他手的話要能夠找出適當的把位。例如：B 大調三級和弦是 D#m7、關係小調是 G# 小調、平行小調是 B 小調；吉他還要知道 B note, D#m7, G# minor scale 在哪裡 ..... 等資訊。有點像是背單字必須要的聯想，但是還是有方法記憶的 "五度圈"。

為什麼要這樣？現場的表演是以主唱為主角 (練團室裡大部分以鼓手的 Click 為主)，換言之，主唱的 Key 就是樂團要跟的。如果主唱今天的狀況不好，想要降個 Key，那麼樂手就要跟。如果樂手今天很 High 想再來兩個全音，那麼樂團就要升兩個全音。(去 Youtube 找同一首曲子，不同的 Live 地點，不同的團翻唱，Key 不一樣是常有的事。)

大部分的時間舞台上樂手都是屬於配角 (在台灣)，除非是演奏形式的樂團、或者是有 Guitar Hero 的團 (不過這種團在台灣很少，很少聽眾會去留意樂手)

大部分的調性利用基本的指型平移都不難理解，同時也不難彈奏，但是有一些調性我個人就建議要特別的熟練一下：

  1. C、G: 這不用說，最基礎的調性.
  2. C# (Db), G# (Ab): 這幾個調性常會出現在上面 C, G 兩個附近, 也就是如果一開始的 Key 是 C or G, 那麼可能最後都會升 Key, 經驗法則常常會是升半音, 所以遇到 C#, G# 的機率很大.
  3. B, Gb (F#): 同上, 但這是 C, G 的降半音. 喜歡彈一些有 Guitar Hero 的歌, 常會遇到, 如果要做原Key, 但是又不想降半音的話 ...
  4. D, E, A: 如果喜歡 Acoustic Guitar 伴奏或者 Finger Style 的朋友可以多研究這三個調. 有很多精采的曲子, 吉他的編的非常漂亮, 通常都是這三個調.
  5. E, A, G, C: 玩 Blues 很常遇到, 同時也要練習這幾個的平行調.
  6. Eb, Bb: 如果有機會跟 Saxophone 搭音樂, 這兩個調要多練.

很多以吉他為主的樂團，他們的歌曲很多都是吉他降半音來彈奏的。像是 GNR 的曲子，Slash 幾乎都是降半音在彈琴的；Bon Jovi 、The Calling、Mr. Big、Robbin Williams .... etc。這時候要跟他拼 B 大調嗎？還是現場再來把弦一根一根慢慢的降半音？呃，不過基本上現場的音樂總監不會允許你這麼做，而且別忘了降 Key 是要全部的樂手都要 ... 所以，如果沒有準備第二把 Open-B 的吉他，保險的方法就直接彈 B 大調吧。

可是 Don't Cry B 大調 (Ab 小調) 怎麼彈？原本很簡單的 Am 、Dm 變成 Abm、Dbm .... 用 La 把位的和弦來彈嗎？Sweet Child 'O Mine 怎麼彈？所以不要懷疑，全部的調：聽覺有十二個、視覺上有十五個，都要練。包含各個調的常用順階和弦、開放順階、Power Chord 順階指型等。

稍微留意一下綜藝節目的現場樂師，來賓歌手只要一清唱，很快的，通常不會超過四個小節，樂隊就會自動跟上了。想像你是現場伴奏的樂手，那麼你要花多少時間跟上？
