聊聊 MIDI Guitar

September 28, 2006 · 8 min read

今天跟朋友聊到 MIDI Guitar 這個東西，想起以前在摸索 MIDI 時幹過的一些蠢事......

當時在作歌的時候主要是以一台 Yamaha PSR 320 做為輸入工具，但是完全沒有鋼琴基礎的我，用鍵盤輸入實在很痛苦，拍子對不準，和弦也按不好，唯一能做的大概就是彈主旋律。很多情況是一次錄一個小節，然後再用滑鼠去慢慢修改。

如果遇到的歌曲是木吉他伴奏的，那麼就更麻煩了。這類歌曲在錄音時，常常會玩立體音，每一個音都會在左右兩邊跑來跑去，聽起來會很有空間感。要做這樣的曲子，以往的做法都是開兩個到四個 channel，然後先彈一個部分，然後重複三次，所以共有四個 Channel。相位由最左到最右。最後把每個和絃內音分散到每一個 Channel。然後就可以做出原本 CD 的效果。但是這樣作實在是太辛苦了，而且未必會真的像吉他的伴奏。可是當時我還是作了很多首歌@@"

那時候樂器最熟練的大概就是手邊的一把古典吉他。所以就去樂器行問老闆是否有可以用吉他當成 MIDI 輸入的介面。那時候老闆剛好進一套 G-VOX System 的 MIDI Guitar 介面/教學軟體 (後來好像被併購了)。一時意亂情迷之下，我就分期敗下來了。(共花了多少錢.....?? ㄟ....內洽@@.....這件事情，一直瞞著老爹@@.....被他知道，大概會被扁成圓的....) 。當然古典吉他是沒有辦法當成 MIDI Guitar 的，所以當時的我是丁丁 @@...

接下來就我就來班門弄斧介紹一下 MIDI Guitar/Guitar Synth，如果有前輩高人看到有不對的，還請給予指正，感謝。

什麼是 MIDI Guitar?

介紹 MIDI 吉他之前，首先，需要對於 MIDI 有一個基本的認識，最好瞭解基本的 MIDI Message 組成，包含 MIDI Note (note, duration, velocity ... etc) 和 MIDI Event, 常用的 Control Message (CC#01, #07, #11, #64, Modulation Wheel) 的基本概念 ... 等。

再來就是對於吉他發聲物理原理，拾音器原理，聲音的物理概念 (純音、樂音、噪音 ...)，要有基本的概念 ...

然後就是瞭解電吉他的基本演奏技巧，如基本的和弦組成、推弦 (Bending)、顫音 (Vibrato)、延音 (Sustain)、力度 (Velocity)、悶音 (Mute) ... etc.

MIDI 吉他的基本原理

MIDI Guitar 基本的願景就是要把 Player 彈奏的音符、表情、動態、Timing ... 等物理現象透過 Converter 轉換成 MIDI Message。這邊的 MIDI Messsage 不是指 Windows 裡面的 WAV 檔，而是一些紀錄音符資訊的資料。例如：

  • MIDI Note:

  • 彈奏 C3 (Note Number / MIDI Number)

  • 音符長度是 3 拍 (Duration)

  • 開始的力度是 100, 最後第三拍的力度是 20 (CC#07 or CC#11)

  • MIDI Events:

  • 第一拍有推弦 Bending、由 C5 推到 D5 (Modulation Wheel)

  • 第二拍的地方開始有顫音 Vibrato (CC# 01)

這些都是 MIDI Message，多寡不一，端看 Converter 處裡的方式與精確度。~~越精確、處理速度越快的 Converter，當然就越好。~~處裡出來的結果和一般預期的越接近越好. 當然啥叫做 "一般預期" 就不容易認定了, 所以有些廠商的機器會提供各式各樣的模式來滿足使用者的需求.

這些 MIDI Message 處理完之後，送給 Sequencer (EX: Cubase, Sonar ...) 就可以作適當的編輯，當然可以在 Sequencer 中指定這個訊息送給什麼樣的 Bank、什麼樣的 Tone。例如送出去的目標是 Piano，那麼結果就是用吉他，彈出鋼琴的聲音，當然也可以彈出鼓、Sax、小提琴 .... 看你怎麼玩囉~~

因為物理現象可以透過 Converter 轉換成 MIDI Message，可以作跟合成器類似的事情，所以 MIDI Guitar 又可以叫做 Guitar Synthesizer 吉他合成器.

什麼人需要用 MIDI Guitar?

其實只要是 Guitar Player 都可以玩 MIDI Guitar，不過比較適合的有幾種：

  1. 不熟悉鍵盤，而需要從事編曲工作的吉他手，或者編曲時需要編的更像吉他。我大概就是了...
  2. 現場的 Player：需要用一些 MIDI Message 作效果的樂手。例如玩 New Age 的可以作 Pad 的效果。
  3. 錢太多的人。這種東西，基本上都不便宜...
  4. 從事音樂教育工作者、編曲教學

MIDI Guitar 的一些優點：

  1. 讓吉他手也可能玩 MIDI 編曲。傳統的 MIDI 編曲還是以鍵盤作為輸入設備，但是有的 MIDI Guitar 之後，同樣的工作，吉他也可以當成輸入設備!! 而且比 KB 能夠編出像吉他的作品!
  2. 現場演奏時，可以作出更多特殊的效果.....像用吉他打鼓、彈鋼琴、吹喇叭、拉小提琴 ... KB 能做到的，GT 也都能做到，簡單說就是搶 KB 手飯碗 XD~~~
  3. MIDI 有的特性，只要能夠轉換成 MIDI Message，大概都做得到...

MIDI Guitar 的限制:

  1. 吉他噪音的部分無法正確的轉換成 MIDI Message，像是悶音、刮弦 .... 等等
  2. 音準，吉他音準是屬於不穩定型的樂器，所以透過 MIDI Guitar 彈出來的東西，音準不會太準，如彈鋼琴，會像沒調音的鋼琴。
  3. 會因 Converter 處裡的強度，會有不同的轉換結果。
  4. 演奏時，手法要彈的非常乾淨，否則會有一堆 Unwanted notes。換句話說，MIDI Guitar 可以測試一個吉他手基本功是否夠紮實！

MIDI Guitar 一些相關產品資訊:

最著名的產品大概就是 Roland 的 GR 系列。他有兩個部分，一個是拾音器，一個是合成器音源。Roland 的產品來說就是 GK-2A MIDI拾音器跟 GR-33 這兩者作搭配。其他還有很多可以參考這裡。

Roland 還有另一個 VG 系列 (VG8, VG88, VG99) 的產品。他是以 Modeling 為基礎的技術，他無法送出 MIDI Message。因為是屬於 Modeling 技術，VG 可以模擬很多其他的吉他的音色，效果很不錯。如 Gibson LP、Fender Telecaster、Stratocaster、古典吉他、木吉他、十二弦吉他、斑鳩琴。

但是 VG99 除了可以模擬吉他音色, 也可以做 Guitar to MIDI, 所以他也可以當作 MIDI Guitar 使用.

樂器大廠 Yamaha 也有類似的產品 G1D。另外吉他效果器廠商 Line6 的 Variax 也是以 Modeling 為基礎的技術，聽說效果也相當不錯。
