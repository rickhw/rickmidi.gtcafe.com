基礎聲學與數位音樂製作

對於 "聲音" 的物理現象，很多物理學、音響或 PA 相關的書都會提到一些基本概念，這些概念對於音樂製作上，尤其要做出比較有豐富聲響的音樂，基礎的聲音理論更是要有相當的瞭解。

軟的? 硬的?

"音源" 決定音樂成品的質感. 軟體音源的出現, 他的效果, 品質, 等各項數據跟傳統的硬體比較起來, 幾乎是以指數曲線的速度在成長. 有朋友問我, 那硬體音源是不是可以淘汰了??

過帶注意事項

類比時代是用 Sequencer 送 MIDI Message 給硬體音源, 然後將硬體音源的類比訊號錄 (過) 到盤帶. 這樣的過程最後被稱之為過帶 (Tracking). 傳統的過帶必須經過類比線路, 雖然聲音不錯, 但是由於類比線路有很多不確定性, 例如外在的雜訊, 線材, 接頭, 同步 (Time Code) ... 等複雜問題, 所以算是一個很辛苦又複雜的過程, 但是卻是混音前必有的步驟.

現在市面上軟硬體產品眾多，但是很慶幸的，大多數廠商都會提供手冊給使用者下載。使用這些器材之前（或者準備添購新器材之前），我們都已經可以從手冊瞭解大部分器材的功能、規格等資訊。

錄鼓的一些基本概念

鼓的錄音是音樂製作中的一項大工程，需要具備基礎知識、技術與設備。本文整理錄鼓所需的認知與注意事項。

錢推出來的

音樂製作品質好壞的因素很多，一般來說，設備跟技術方面的因素 (不講編曲、演奏技巧) 常見的有以下：

鍵盤音色概述

關於音色和演奏手法，我個人習慣以 GM Group 切入去認識，基本上各大廠合成器 (註1) 的音色分類，都可以從 GM 作分支，同時大部分高階琴也都會支援 GM、GM2，有些伴奏琴會支援 GM/GS/XG/GM2 等規格。另外就是現在軟體音源的部份，獨立的產品也差不多都是同樣的分類方式。

襯底 PAD 的基本概念

襯底 (Pad) 是音樂裡製造流動感、呼吸感的長音元素。了解 Pad 的類型與編曲技巧，可以讓音樂更有層次與氛圍。

CC#07 Main Volume 和 CC#11 Expression

CC#07 和 CC#11 是 MIDI Control 訊號裡經常會用到的兩個基本控制碼, 他們基本的功能都是用來控制 Track 音量.

Delay 的應用

Delay 是音樂中很常見效果, 尤其是吉他手更是常用. 它可以潤飾聲音, 彈分散和弦或者 Solo 加一點會很有 fu.

How to synchronize the MIDI messages between MIDI device and sequencer?

上個月跟朋友借了一台 Roland DR-880 來玩. 這台是台很棒的 Drum Machine, 不管是練習, 做場, 個人覺得都很方便. 他的鼓音色根據官方網站的資料是取自 SRX 的音源, 而我也有一張 SRX-01 鼓音源. 實際測試過, DR-880 的 Rhythm 送給 SRX-01 大部分在聽覺上是勉強 OK 的, 但是有一些 Percussion (打擊樂器) 部分的 Mapping 還是跟 SRX-01 不太一樣, 所以 detail 的部分還是要靠編曲者自己去修飾. 而 DR-880 這台機器重點還是在於節奏的部分, 他內建相當多豐富且實用的節奏, 因此讓我想把他擷取出來蒐藏到個人的素材資料庫裡, 日後在創作時有更多的材料可以選擇.

Loop 的概念與應用實例 - One Night in 北京

Personal Mixer / Monitor System (個人監聽/練團系統)

在台灣玩樂團一直是夾縫中求生存的, 一個標準樂團編制的樂手所製造的 "樂音" 在一般的公寓裡是很難被允許的 (想跟警察杯杯很熟的話可以試看看). 除非有相當的財力, 裝潢自己的練團室 / 錄音室, 否則一般樂手們只能去租練團室, 然後大家去那邊練團. 但是練團室的設備 / 狀況 / 空間大小不一,  所以每次練團可能都會要重新適應.
