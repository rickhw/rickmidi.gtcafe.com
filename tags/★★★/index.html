一些關於鍵盤與MIDI 的 FAQ

最近有朋友 (吉他手) 因為教學跟表演需要, 買了一台 Yamaha PSR-3000 作為工作的新夥伴. 同時他也希望能夠用鍵盤本身的音源來播放網路上抓的 MIDI 檔. 另外樂團的鍵盤手想把自己的靈感記錄下來, 進而用 Cubase 編曲. 但是都遇到幾個類似的問題:

五度圈

五度圈 (右圖，取自 Wiki 百科) 是一個音樂工具，有點像是九九乘法表，因為很多觀念、理論都可以透過它來幫助理解、記憶。特別是關於和聲學方面的理論，五度圈更是格外的重要。

以現代西洋音樂的基礎討論如何自行創造一個不一樣的音階。

吉他手如何自學鍵盤?

也是一篇我在鄉民站 Keyboard 版 po 過的文字, 主要是討論吉他手如何自學鍵盤. 這邊說的 "學鍵盤" 指的是基本的鋼琴演奏技巧, 不包含合成器, MIDI 編曲等概念.

吉他手怎麼練習音感

一般沒有受過訓練的樂手對於音感每個人都有自己的練習方式，不管是多抓歌還是寫譜都是一些不錯的方式。這邊提供我自己過去練音感的心得，希望對想要練習採譜 (Transcription, 台灣俗稱 "抓歌"、內地稱 "扒帶"、廣東話叫 "執歌" ) 的朋友能有所幫助。

吉他的空弦聲響

吉他跟其他樂器比較起來, 有一個特色是讓很多人著迷的 - 同音異弦. 簡單說同樣一個音 C 會有不同的位置, 然後因為弦的粗細不同, 所以雖然音高是一樣的 (頻率一樣), 但是音色不一樣. 正因為這樣的特點, 雖然只有六根弦 (一次只能同時發出六個聲音), 但是吉他卻有著豐富且多變的和弦聲響.

和弦基礎

我大致上整理一下我自己對和弦理解的整個概念。依據組成音分成四大類：三和弦、七和弦、延伸和弦、其他。和弦的學習和記憶方式可參閱和弦學習地圖，吉他和弦的學習請參閱 "吉他和弦聲位的基本概念"。

前級、後級、單體

玩電吉他跟一般木吉他, 古典吉他最大的差別就是電吉他多了電 .... 所以電吉他如果只是一把吉他, 基本上不能算完整, 完整的應該要包含 '電' 的部份. 因為多了電的部份, 使得電吉他除了吉他本身之外, 最常被提到的話題就是音色 (Tone, 痛).

音階的本質

在學習音階的過程中，我心裡一直有個疑惑，為什麼要叫做自然大調音階？自然小調音階？為啥是自然的？不是人工的？為啥又會有調式這種東西存在？

音階基礎

西洋樂理以巴哈十二平均律為基礎。平均律定義了音階的物理關係，將倍數頻率 (ex：220Hz - 440Hz) 以指數關係分成十二個半音，我們又依據聽覺的協和度定義了音程關係，以音程關係加以排列組合，形成各式各樣的聲響特色、顏色，經由先知們整理過後，形成我們目前使用的音階系統。

基礎聲學與數位音樂製作

對於 "聲音" 的物理現象，很多物理學、音響或 PA 相關的書都會提到一些基本概念，這些概念對於音樂製作上，尤其要做出比較有豐富聲響的音樂，基礎的聲音理論更是要有相當的瞭解。

軟的? 硬的?

"音源" 決定音樂成品的質感. 軟體音源的出現, 他的效果, 品質, 等各項數據跟傳統的硬體比較起來, 幾乎是以指數曲線的速度在成長. 有朋友問我, 那硬體音源是不是可以淘汰了??

減七與半減七和弦於流行樂中的應用

這兩個和弦的組成音只有差一個，同時因為聲響都很緊張，所以採譜時不太容易辨識。為了辨識這兩個和弦的差異，我用一般流行歌曲中慣用的編曲手法，以及樂理上的概念分析他們應用上的差異。

鍵盤音色概述

關於音色和演奏手法，我個人習慣以 GM Group 切入去認識，基本上各大廠合成器 (註1) 的音色分類，都可以從 GM 作分支，同時大部分高階琴也都會支援 GM、GM2，有些伴奏琴會支援 GM/GS/XG/GM2 等規格。另外就是現在軟體音源的部份，獨立的產品也差不多都是同樣的分類方式。

唱名 Do Re Mi 大家都知道，但是唱名只有七個，音樂的一個八度卻有十二個音，那其他的音應該怎麼唱？

關於樂團總譜

在 "怎樣練一首歌" 以及 "樂團經營" 提到段落的問題. 樂團是一個 "團體", 音樂是時間藝術, 成員在練習時就要有共同的時間軸參考標示 (Marker/Tag), 溝通時就用 Tag 溝通, 協調. 盡量用通用的術語, 或者英文, 因為搞不好有機會跟老外合作搭歌. (聽聽陶喆跟老外工作時的對話)

CC#07 Main Volume 和 CC#11 Expression

CC#07 和 CC#11 是 MIDI Control 訊號裡經常會用到的兩個基本控制碼, 他們基本的功能都是用來控制 Track 音量.

Personal Mixer / Monitor System (個人監聽/練團系統)

在台灣玩樂團一直是夾縫中求生存的, 一個標準樂團編制的樂手所製造的 "樂音" 在一般的公寓裡是很難被允許的 (想跟警察杯杯很熟的話可以試看看). 除非有相當的財力, 裝潢自己的練團室 / 錄音室, 否則一般樂手們只能去租練團室, 然後大家去那邊練團. 但是練團室的設備 / 狀況 / 空間大小不一,  所以每次練團可能都會要重新適應.

Roland 的新玩具: 吉他合成器 VG-99

Roland VG-99 Guitar System

VG Stratocaster
