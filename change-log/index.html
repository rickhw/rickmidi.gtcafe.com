    • Blog 左側欄顯示最近文章，並新增依月份整理的 Archives 入口。

2026-05-31​

    • 示範文章內圖片與 cover image 的 colocated asset 放法，並設定 Open Graph / Twitter preview image。
    • 調整 Blog 文章網址格式為 /blog/yyyy/mm/dd/title。
    • 將既有 docs 的 Uriel like/comment 外部服務套用到 Blog 單篇文章頁。
    • 新增 Blog 文章右側欄的文章資訊、Like、TOC、相關文章與 Tags 區塊。
    • 將 Blog 文章的 Like 從文章開頭移到右側欄，並保留 comment 在文章內容下方。
    • 在 Blog 範例文章加入 related front matter，示範站內與外部相關文章連結。
    • 調整 Blog TOC 標題樣式與 h2/h3/h4 目錄層級範例。
    • 調整 Blog 版面，讓左側 Recent posts 與右側文章 meta 欄等寬，並在左右側欄和文章中間加入垂直分隔線。
  • Docs：
    • 將 Blog 文章右側欄的文章資訊、Like、TOC、相關文章與 Tags 結構套用到 docs 文章頁。
    • 將 docs 文章的 Like 從文章開頭移到右側欄，comments 保留在文章內容下方。
    • docs 文章支援 related front matter，可設定站內 to 與外部 href 相關文章連結。
    • docs 文章右側 TOC 加上 目錄 標題，並在文章與右側欄之間加入垂直分隔線。
