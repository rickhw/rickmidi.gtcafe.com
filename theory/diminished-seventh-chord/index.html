減七和弦 (Diminished Seventh)

減七和弦的音程關係是 1 b3 b5 bb7, 四個組成音剛好將一個八度分成四等分. 換句話說, 以 Cdim7 來說, 其組成音是 C Eb Gb Bbb, 同時有四個同音異名的兄弟姊妹:

  • Cdim7 => C Eb Gb A
  • Ebdim7 => Eb Gb A C
  • Gbdim7 => Gb A C Eb
  • Adim7 => A C Eb Gb

這四個和弦有著不同樣的名稱, 但是其組成音其實都是一樣的. 不同的是組成音的次序不同.

記憶減七和弦的方式：

記憶上, 減七和弦可以從屬七和弦 (Dominant Seventh) 來記憶. 因為除了根音, 其他三個音剛好是跟屬七和弦差一個半音.

  • C7 => C E G Bb
  • Cdim7 => C Eb Gb Bbb

紅色的地方剛好差一個半音. 所以記憶的方式通常就是 ... 原和弦的屬七和弦, 根音加一個半音, 就可以得到減七和弦. 所以以吉他來說, 按一個屬七和弦 C7, 只要把根音升半音就會得到 C#dim7 (C# E G Bb); 或者 C7 根音不變, 其他三個音降半音就會得到 Cdim7 (C Eb Gb Bbb). 如下圖:

另外, 減七和弦也可以從半減七和弦 (Half-Diminished Seventh, Xm7-5) 推算. Cm7-5 => C Eb Gb Bb. 把 Bb 再將一個半音, 也就是重降 B => Bbb. 同樣可以得到 Cdim7. 所以另外一種記憶法就是從 Xm7-5 推算.

附帶一提的是, Xm7-5 根 Xdim7 的記憶方式很類似, 減七可以從屬七推算, 半減七則可以從大七推算. 例如: Cmaj7 (C E G B), 把根音升半音, 其他的不動 (先發制人), 則得到 Dbm7-5 (Db E G B); 根音不動, 其他三個降半音 (敵動我不動), 則得到 Cm7-5 (C Eb Gb Bb). 如下圖:

基本應用：

流行樂常會用在兩個相差一個全音的和弦進行之間. 最常見的例子如:

  1. C -> Dm 可以改成: C -> C#dim7 -> Dm
  2. F -> G 可以改成: F -> F#dim7 -> G

這樣的使用技巧, 樂理上可以用次屬和弦 (Secondary Dominant) 解釋. Cmaj7 到 Dm7 時, 可以在 Dm7 前面放一個 V7 of Dm = A7.

其中 A7 (A, C#, E, G), A7 與 C#dim7 (C#, E, G, A#) 共用了 C#, E, G 三個音. 所以 A7 可以用 C#dim7 代換, 代換之後同時剛好造成半音的 Bass Line (C -> C# -> D).

  • Cmaj7: C E G B
  • C#dim7: C# E G A# <==> A7: A C# E G
  • Dm7: D F A C

類似的例子, 都可以用同樣的方式解釋.

  • F -> G of C Major 可以改成 F -> D7 -> G, 因為 D7 為 G 的五級;
  • 或者改成 F -> F#dim7 -> G
  • Fmaj7: F A C E
  • F#dim7: F# A C Eb <==> D7: D F# A C
  • G7: G B D F

轉位應用:

文章一開始就說明, 減七和弦有四個轉位兄弟, 組成音都一樣, 但是位置不一樣.

所以上述的基本應用也常會被改成這樣:

  • 原本的進行: C -> C#dim7 -> Dm, 可以用以下代換:

  • C -> Edim7 -> Dm

  • C -> Gdim7 -> Dm

  • C -> A#dim7 -> Dm

  • 原本的進行: F -> F#dim7 -> G, 可用以下代換:

  • F -> Adim7-> G

  • F -> Cdim7 -> G

  • F -> D#dim7 -> G

除了上述這種代換方式, 實際上在一般木吉他的伴奏裡, 只要出現減七和弦, 就一樣可以用轉位來代換.

進階應用:

另一種進階應用, 是利用延伸和弦 (Extended Chord) 代換減七和弦, 如上述的例子:

  • F - F#dim7 - G  (Key: C)

可以把其中的 F#dim7 換成 D7b9, 比較這兩個和弦的組成音:

  • F#dim7: F# A C D#
  • D7b9: D F# A C D#

另一個常見的調性:

  • C - C#dim7 - D  (Key: G)

可以換成:

  • C -  A7b9 - D

這些 Extended Chord 的基本概念和吉他指型按法請參考 "Shell Chord" 的說明.
