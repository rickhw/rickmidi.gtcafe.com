五度圈

五度圈 (右圖，取自 Wiki 百科) 是一個音樂工具，有點像是九九乘法表，因為很多觀念、理論都可以透過它來幫助理解、記憶。特別是關於和聲學方面的理論，五度圈更是格外的重要。

記憶五度圈方法：

五度圈基本的讀法，從 C 開始以順時針方向，每個音之間相差完全五度的關係，G 是 C 的完全五度、 D 是 G 的完全五度 ... 類推；逆時針為完全四度音 C 是 G 完全四度、 F 是 C 的完全四度 ... 類推。最後兩者剛好都會形成固定的循環。

記憶五度圈的方式，一直唸著 CGDAEB、 .... 基本上這種方法我是記不起來的，我大概只能背到上面寫的部份。不過剛開始我其實只有記前面五個，因為：

LevelIVIIVIIII
0CGDAE
bBGbDbAbEb
bbBbFCGD

第二行剛好差第一行一個半音，第三行也是。所以唸到 B 的時候就知道已經開始重複了。

五度圈的應用：

這部份網路上已經有很多類似的訊息，我只條列重點出來，詳細的訊息可以查閱最後的參考資料部份。

  1. 推算各調的五度（順時針）、四度（逆時針）音或者和弦
  2. 各調調號的升降記號及個數：順時針升記號、逆時針降記號
  3. 練習各調音階、順階和弦等循環、轉調 (聽覺上十二個調、視覺上十五個調)
  4. 找 ii-V-I 進行 (逆時針)

五度圈在吉他上的應用：

  1. Power Chord：會按 Power Chord 就應該知道五度音在哪、就可以知道五級和弦在哪、就可以做出終止式。

  2. 四度音：指板同一把位上，除了三到二弦是大三度關係，其他由低音到高音相鄰兩弦都是完全四度。只要知道現在的位置，透過五度圈逆時針就可以馬上知道四度音是啥。

  3. Pattern 指形：五度圈跟 Pattern 有關係？沒錯，記憶方法我提到我剛開始只有計前面五個：CGDAE。仔細看看這五個和弦放在開放把位來看，不正好就是五個 Pattern 指形的一級和弦？

    • Pattern 1 (Mi 形) 大調音階的一級 C
    • Pattern 3 (La 形) 大調音階的一級 G
    • Pattern 5 (Re 形) 大調音階的一級 D
    • Pattern 2 (Sol 形) 大調音階的一級 A
    • Pattern 4 (Ti 形) 大調音階的一級 E
      剛好可以練習 I-V 轉調。練習 ii-V-I 進行也不錯用！

    五個音階及和弦指型詳細介紹請參閱 "吉他音階學習引導", "吉他的和弦聲位基本概念" 的說明.

結論：

五度圈是學習音樂一個很重要的工具，就像數學的九九乘法表一樣重要，對於之後學習各項理論、分析、都有相當的幫助！
