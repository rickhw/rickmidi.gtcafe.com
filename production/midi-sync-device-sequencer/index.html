How to synchronize the MIDI messages between MIDI device and sequencer?

上個月跟朋友借了一台 Roland DR-880 來玩. 這台是台很棒的 Drum Machine, 不管是練習, 做場, 個人覺得都很方便. 他的鼓音色根據官方網站的資料是取自 SRX 的音源, 而我也有一張 SRX-01 鼓音源. 實際測試過, DR-880 的 Rhythm 送給 SRX-01 大部分在聽覺上是勉強 OK 的, 但是有一些 Percussion (打擊樂器) 部分的 Mapping 還是跟 SRX-01 不太一樣, 所以 detail 的部分還是要靠編曲者自己去修飾. 而 DR-880 這台機器重點還是在於節奏的部分, 他內建相當多豐富且實用的節奏, 因此讓我想把他擷取出來蒐藏到個人的素材資料庫裡, 日後在創作時有更多的材料可以選擇.

如果你有一台 Keyboard, 不管是伴奏琴, 合成器, 或者電鋼琴都可以, 而你想把裡面的伴奏資料, 或者是多 Channel 演奏 (分鍵演奏) 資料弄到電腦上, 然後重新編輯. 或者你有類似 DR-880 這樣的機器, 想要跟我一樣把裡面的節奏撈出來 Reuse. 那麼也許可以參考我這篇介紹.

首先大概必須要具備的基本概念有:

  1. 瞭解 MIDI 的基本概念, 運作原理.
  2. 瞭解 Track 跟 Channel 的差別. 雖然中文可能都翻成 '音軌' ... 詳細請參考中文資料: Channel, Track
  3. 有適當的 Sequencer, 不管是軟體 (Cakewalk, Cubase) 還是硬體 (Ex: Yamaha QY 系列, Roland MC 系列) 都可以
  4. 當然你的 MIDI Controller (鍵盤或者 Drum Machine) 必須具備標準 MIDI I/O, 支援 MTC/MMC 同步訊號

大概的步驟如下:

  1. 決定 Master / Slave: 這個例子是 DR-880 送 MIDI Message 給 Sequencer. 所以可以把 DR-880 當成 Master, Sequencer 當成 Slave. 這裡 Sequencer 用 Cakewalk Pro 9.0 當例子. 其他產品或者硬體設定請參閱手冊.

    • DR-880: Sync Mode 指定成 Internal, 也就是被指定成 Master Device. 鼓指定到 Ch10, Bass 指定到 Ch2
    • Cakewalk: Sync Mode 指定成 MIDI, 也就是 Slave.

  2. 在 Cakewalk 中選擇對應的 Data Channel. 選擇好之後, Enable 要錄的 Track 部分 (可能要同時錄很多個 Channels), 然後按下 Record 按鈕, 應該會看到 Cakewalk 下方狀態列有一段訊息在閃爍著, 表示正在等待 Start 的 Message.

  3. 開始錄製: 按下 DR-880 的 Play 開始播放 Rhythm. 順利的話這時應該會發現 Cakewalk 已經開始在接收 MIDI Messages 了

接下來這些資料如何利用, 就看個人的巧思跟創意了 ~~
