Breath Controller 吹管控制器

在吉他之神 Eric Clapton - One More Car, One More Rider (2002) 演唱會上, 在 Wonderful Tonight 一曲中的後半段, 不難注意到有一個 KB 手的演奏方式除了彈鍵盤, 還要 "吹". 然後音樂之中就會有一個類似 Saxophone 般迷人的音色出現, 但是現場就是看不到 Saxophone 手.

那個 KB 手叫做 David Sancious (Wiki), 而他嘴巴上吹的東西叫做 Breath Controller (吹管控制器), 也就是用來模擬吹管樂器的一種介面. 讓彈出來的旋律有呼吸感, 有吹氣的感覺. 基本上, 可以把他看成另一種樂器, 也可以把它當成吹管樂器跟鍵盤樂器的合成體.

吹管控制器基本上的原理還是建立在 MIDI 的 Control Message 上, 利用控制器偵測到的物力現象, 轉換成 CC#02, 之後同樣由 Sound Module 發聲. 不同的是透過吹管控制器可以更完整的呈現 Breath 的感覺, 達到擬真的效果. 基本上跟所謂的 MIDI 吉他是類似的架構. 關於 MIDI 吉他可以參考小弟另外寫的一篇文字 -> 這裡.

代表性的產品就是 Yamaha 的 BC3A 吹管控制器 (如下圖, 圖片摘自 Yamaha 官方網站). 因為 BC3A 是 Yamaha 自訂的介面規格, 所以其他廠牌的鍵盤, 像是Roland Fantom X 就無法使用. 但是還是有玩家想出辦法, 自己弄個轉接器, 然後一樣可以玩.

另一個也是極具代表性的產品: AKAI EWI (Electric Wind Instrument, 電子吹管樂器, 如下圖). 基本上他複製 Saxophone 的吹奏方式, 同時結合音源. 指法, 跟吹奏方式基本上跟 Saxophone 一樣, 不同的就是他可以獨立搭配不同的音源.

使用 EWI 最有名的就是日本融合爵士樂團 T-Square 了, 他們先後的 Saxophone 手都大量的在他們的音樂中使用該樂器. 更多 EWI 請參閱國內的 Saxophone 手米羅的詳細介紹: "AKAI E.W.I".

相關樂器產品:

  1. Yamaha BC3A 吹管控制器
  2. Yamaha WX5 風笛 MIDI 控制器
  3. Yamaha VL70-m 物理模型音源
  4. Akai EWI 3020 電子風笛, T-Square 用很多在他們的歌曲中
  5. MIDI Solutions Breath Controller: Breath Controller 的轉接器, 讓非 Yamaha 的琴也可以使用 BC3A
  6. USB MIDI Breath Controller

使用過的樂手:

  1. David Sancious (Wiki): 與眾多大師合作過的鍵盤手, 如 Eric Clapton, Santana, Sting ... etc
  2. T-Square 先後 Saxophone 手 - 伊東毅, 本田雅人 也都使用過 EWI 演奏過.
