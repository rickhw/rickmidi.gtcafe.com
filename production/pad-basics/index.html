襯底 PAD 的基本概念

襯底 (Pad) 大部分指的是音樂裡的一些長音、流動的聲音。

主要的功能就是製造出音樂的呼吸、流動感，和構成音樂的面，讓聆聽者可以進入一種氛圍、氣氛之中。通常襯底會出現在慢歌或者情緒轉折處，或者點不多的音樂中。

襯底通常是一個和弦長音背景，最常見的就是用弦樂，或者合成樂器。另外一種就是用具有戲劇效果的「音效」作襯底，例如自然音樂裡常常出現的蟲鳴鳥叫聲、流水聲。

Pad 的層次分配​

在編曲時，可以將襯底分成幾個部份：

類型功能Pan 位置
High Pad高音，讓 pad 更有空間感。可使用和弦外音、Tension note 等製造緊張的音程L / R
Middle Pad定義和弦，如果已經有 Low Pad，可以省略和弦根音、五度音。三度音、七度音不可省略L / R（可多個）
Low Pad定義低音Center
Bass比 Low pad 低一個八度Center
FX Pad效果襯底，各種合成音色、取樣音效等L / R

Pad 音色常用的種類​

Traditional（傳統樂器、原音音色）​

Organ、E-Piano、Acoustic Guitar、String、Wind 等。音樂聽起來比較傳統、古典、一般。

Orchestra（管弦樂團編制）​

音樂聽起來華麗、磅礡。不過編管弦樂團該具備的知識是要有的。

Soft Pad​

比較沈澱、安定、安靜。聽起來有安定的感覺。通常 New Age 的音樂使用的最多。

Bright Pad​

比較亮的襯底。感覺是亮麗、愉悅的。New Age 也用的很多。

Synth​

現代感、新、科技、時尚感。90 年代的音樂常用。

Effect Pad（Vox、FX、Loop）​

特效、效果、音效等。營造特殊氣氛、環境 ... 電影配樂常用。

Pad 編曲時的使用技巧​

建立層次感​

  • 注意出現的依序
  • 同類型的 Pad 可使用多個，每個分別用在不同的音程上
  • 調整不同的 Pan 跟 Volume，建立層次感

流動、呼吸感​

  • 使用 CC#07 或 CC#11 製造流動、呼吸感
  • 注意音與音之間的連續性 (Legato)、流動感 (Flow)、呼吸 (Breath)

弦樂技巧​

  • 如果使用 Strings 的音色 (GM 49, 50)，中間可以再疊一把小提琴。弦樂整體感覺會更厚實、更真實
  • High String：經常使用 Counterpoint（對位法）、Harmony（和聲）編

其他​

  • 搭配 Loop 使用，穿插適當的 Percussion

樂團 Pad 的使用​

鍵盤手​

最常負責 Pad 的是鍵盤手，Full Strings 是最常用的。Piano 跟 String、Vox、Soft pad 都是經常看到的組合。

  • 伴奏時：使用 Piano + String 以 7:3 的音量比例彈奏。同時演奏時注意 Sustain 的使用時機，避免 String 過多糊成一團
  • Solo 時：視歌曲狀況，Piano + String 可以是 7:3 或 5:5 或 3:7

吉他手​

若要幫忙彈 Pad，一般就是 Clean + Chorus + Delay，注意 Pick 彈奏角度。

鼓手​

用輪鼓製造出面的感覺。

現場演出重點​

現場樂團彈奏慢歌的成敗：主唱本身的 fu，再來就是 Pad 的控制。
